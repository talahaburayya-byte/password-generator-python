# password-generator-python
A simple Python password generator with input validation and random characters.
 Password Generator
A simple Python project that generates a random password based on the number of characters entered by the user.

Features
- Asks the user for the desired password length.
- Requires at least 6 characters.
- Handles invalid input using "try/except".
- Includes:
  - Lowercase letters
  - Uppercase letters
  - Numbers
  - Special characters
- Shuffles the generated password to make it random.

Concepts Used
- "input()"
- "while" loops
- "for" loops
- "try / except"
- Lists
- "append()"
- "random.shuffle()"
- "string" module
- Type conversion using "int()"

How It Works
1. Enter the number of characters you want.
2. The program checks that the input is a valid number.
3. The password must contain at least 6 characters.
4. The program selects different types of characters.
5. The characters are shuffled.
6. The final password is displayed.

Example
How many characters for the password: 10

Generated password:
aB7@xK2!mQ
